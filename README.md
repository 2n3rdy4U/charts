## Structure

```
macro/          Economic Data Dashboard (FRED + NY Fed)
cc/             CC ABS Market chart
abs/
  issuance/     Consumer ABS Issuance Activity
  explorer/     ABS Data Explorer (loan-level SEC filings)
  vintage/      Vintage delinquency curves
  schedule/     Filing schedule and publication calendar
```

## Notes

- All files are self-contained HTML (data embedded inline) unless noted.
- `abs/explorer/` and `abs/vintage/` load CSV data files from the same folder.
- Generated by private pipeline in `abs-scripts` repo. Do not edit HTML files directly.
